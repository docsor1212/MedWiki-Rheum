🔬 PubMed文献引用验证工具

pubmed-verifier v1.3.0 · 一键检测AI编造的虚假文献引用 · 纯本地运行，零隐私泄露

一句话：自动调用PubMed API批量验证PMID引用的真实性和内容匹配度，5分钟完成225条引用的全量审计。基准测试：存在性验证精确率/召回率/F1 = 100%，内容匹配率95%，速度约34 PMIDs/min。

📌 功能一览

🔍
PMID存在性验证
逐条调用PubMed E-utilities API（esummary），确认PMID是否对应真实文献。支持批量查询（50条/请求），自动限速（3 req/s）。
📋
元数据提取
自动获取标题、作者、期刊、发表日期、DOI等完整元数据，便于人工核实。
🎯
内容匹配检测
从文件名提取关键词，与文献标题做overlap匹配。内置70+医学缩写映射表（sJIA、SAVI、cSLE、GIO等），自动展开后匹配，匹配率达95%。
🔄
替代文献搜索
发现无效PMID时，自动调用PubMed esearch根据关键词搜索推荐替代文献，返回候选PMID列表。
🧠
跨领域引用识别
智能标记低匹配度引用（不自动删除），区分"确实无关"和"跨领域但合理"（如HLH指南被MAS病例引用），保留人工判断空间。
📊
多格式报告
输出HTML可视化报告、JSON结构化数据、终端摘要，满足不同场景需求。

🚀 使用方法

基础用法

1
验证整个项目目录
扫描目录下所有HTML/MD/TXT/JSON文件，提取全部PMID并验证
python3 ~/.openclaw/skills/pubmed-verifier/scripts/verify_pmids.py \ --source /path/to/project \ --output report.html
2
验证指定PMID
直接输入PMID列表，适合快速检查单条或少量引用
python3 ~/.openclaw/skills/pubmed-verifier/scripts/verify_pmids.py \ --pmids 31018962,22213727,999999999
3
启用内容匹配
检查文献标题与文件名/目录名的相关性，标记可能错误的引用
python3 ~/.openclaw/skills/pubmed-verifier/scripts/verify_pmids.py \ --source ./papers \ --match-keywords \ --threshold 0.2

完整参数表

参数必填说明
--source二选一要扫描的目录路径
--pmids二选一逗号分隔的PMID列表
--output否报告输出路径（支持 .html / .json / .txt）
--match-keywords否启用内容匹配检测（默认关闭）
--threshold否匹配阈值 0-1（默认 0.2，低于此值标记为低匹配）

支持的文件格式

.html · .htm · .md · .txt · .json

❓ 常见问题

Q: 需要API Key吗？

不需要。PubMed E-utilities对免费用户开放，自带限速（3 req/s），脚本已内置合规延迟。

Q: 我的论文数据安全吗？

完全安全。脚本只在本地运行，仅向PubMed API发送PMID编号查询，不上传论文内容或文件。

Q: 内容匹配的阈值怎么设？

默认0.2（宽松），适合大多数场景。如果跨领域引用较多可降至0.15，如果想更严格可提高到0.3。低于阈值的引用会被标记供人工判断，不会被自动删除。

Q: 可以用于非医学领域吗？

可以。PMID存在性验证对所有PubMed收录文献通用。内容匹配的缩写映射表可自定义扩展，或直接关闭（不加--match-keywords）。
