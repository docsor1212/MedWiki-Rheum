AESTHETE-AGENT · TECHNICAL NOTES · 07 / INSTALL

三条安装路径

本页色板 · Deep Space Blue(由引擎派生并过闸)

Skill 形态面向编码代理的技能目录;SkillHub 面向国内环境;MCP 形态面向任何支持 Model Context Protocol 的客户端;两者共用同一引擎。

AGENT SKILL

npx skills add docsor1212/aesthete-agent

SKILLHUB · 中文站

skillhub install aesthete-agent --dir ~/.claude/skills

MCP SERVER · PYPI

uvx aesthete-agent-mcp

MCP SERVER · SMITHERY

smithery.ai/server/docsor1212/aesthete-agent-mcp

引擎为纯 Python 标准库实现,安装后完全离线;不需要 API key,不上传任何数据。色板库与偏好档案以 JSON 随包分发,可离线审计。

七页七块色板,全部由同一套角色派生公式渲染——你刚看过的每一页,都是引擎的输出。
